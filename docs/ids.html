Identifiers

Every card, fragment and note has a unique identifier. Identifiers are used to refer to nodes in links and to name the output files and anchors.

The identifier of a card is the value of its id attribute. If the card has no id, the identifier is made of the cardfile name and the sequential number of the card in the file: the third card of notes.deck is "notes.deck-00002".

The identifier of a fragment is the identifier of its card, a dash and the fragment's id attribute. If the fragment has no id attribute, its five-digit sequential number in the card, counting from zero, is used instead. For example, the first fragment of this card has / id top, so its identifier is "ids-top", while this paragraph is "ids-00002".

The identifier of a note is formed in the same way from the identifier of its fragment: FRAGMENT-ID followed by a dash and the note's id attribute, or, if the note has none, FRAGMENT-ID-note-00000, FRAGMENT-ID-note-00001 and so on.

Identifiers must be unique in the deck. Identifiers containing spaces cannot be used in links, so do not use them.

Automatically generated identifiers change when cards and fragments are added or moved, so any node that is the target of a link should be given an explicit id. To find the identifier of a fragment, set

/// +frag.id.show +

and the identifiers will be displayed in the left margin of the output.
