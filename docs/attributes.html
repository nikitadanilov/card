Attributes

Attributes are key-value pairs attached to nodes. card uses some of the attributes to drive the layout and its rendering by the engine. Other attributes can be used by the user for any purpose:

/ C Attribute "C" is not used by card. So it can be used to add comments
/ C to the cardfile. All hail FORTRAN!

An attribute is either a single value (set with key value) or a list of values (extended with +key value). Setting a single-valued attribute again replaces the old value.

List attributes must always be set with the plus sign, even when there is only one value. card does not complain otherwise, but it treats the string as a list of characters: // tags foo tags the card with "f" and "o" (twice). Conversely, +key after a plain key fails with a TypeError. In the reference below, list attributes are marked [list].

Many list attributes are also inherited: when card looks up such an attribute for a fragment, it combines the values set on the fragment itself, on its card and on the deck. This is how styles and automatic links defined once in a configuration file apply to every fragment of the deck. Inherited attributes are marked [inherited] below. They can be set on the deck, on a card or on a fragment.

Deck attributes:

dir: the output directory, relative to the current directory. "html_out" by default. Use "." to write into the current directory.

engine: the output engine. Only "html" (the default) is available.

deck.title: the title of the deck, used in the RSS feed and in the reference to the feed from every page.

deck.description: the description of the deck, used in the RSS feed.

deck.url: the public URL of the output directory. Used to refer to the RSS feed from every page and in the feed itself. Required if any card is in the "timeline" series (see Series and tags).

html.style [list]: CSS appended to the generated style sheet. See HTML output.

html.style.file: the name of the generated style sheet, "style.css" by default.

html.series_compact, html.series_reverse, html.series_flat: when set to a non-empty value, the series links in card footers point to the compact, reversed or flat variant of the series index.

Inherited attributes, usually set on the deck:

em, it, bd, un, cd, ma, al, ar, ac [list, inherited]: style definitions, see Styles.

= [list, inherited]: a link, see Links. Always written as +=.

TeX [list, inherited]: TeX definitions emitted at the top of a card if it contains mathematics, see Mathematics.

html.head [list, inherited]: lines added to the head element of each HTML file.

html.title [list, inherited]: a prefix for the title of each HTML file.

frag.id.show [list, inherited]: if the first value found is "+", the identifier of each fragment is shown in the left margin. Handy when writing links.

Card attributes:

name: the title of the card, shown in its header, in the HTML title and in the indices.

label: the title of the card if name is not set. If neither is set, the title is "Card" followed by the identifier.

id: the identifier of the card (see Identifiers).

brief: a short description of the card, shown in the indices. If not set, the beginning of the card's text is used.

tags [list]: keywords under which the card is indexed:

"The only way to make a man trustworthy is to trust him."
// +tags Stimson
// +tags platitudes

# [list]: the position of the card in a series:

\
// name Card Number Three
// +# trunk 03
// +# chrono 2025/04/01

Attributes above place "Card Number Three" at position "03" in the "trunk" series and at position "2025/04/01" in the "chrono" series. See Series and tags.

html.style [list]: CSS placed in a style element in the card's file.

html.file: the name of the output file of the card. Derived from the identifier by default.

html.anchor: the HTML anchor of the card. The identifier by default.

Fragment attributes:

id: the identifier of the fragment (see Identifiers).

level: the heading level of a head fragment.

url: the source of the image of an img fragment.

width: the width of the image of an img fragment.

html.style [list]: inline CSS style of the fragment. Ignored for headings and display formulae.

html.anchor: the HTML anchor of the fragment. The identifier by default.

>: the indentation level, set by the parser from the leading >-s.

+* is not an attribute, despite the similar syntax: it creates a note, see Notes.

Any node:

DEBUG: the debugging level of the node, see Debugging and caveats. Not inherited.

Finally, card sets a few attributes itself: file, seq, mtime and ctime of a card are the name of the cardfile it came from, its sequential number in that file and the modification and change times of the file. seq of a fragment is its position in the card, and seq of a note is its position in the fragment. The HTML engine also sets card-title on cards and html.file and html.anchor on every card, fragment and note. Treat all these names as reserved.
