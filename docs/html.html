HTML output

The HTML engine writes its output into the directory given by the dir deck attribute ("html_out" by default), which is created if needed. The directory contains:

– one HTML file for each card, named after the card's identifier, unless the card's html.file attribute specifies another name. If two cards have the same file name, the later one overwrites the earlier one, so keep the file names unique;

– style.css (or the file given by html.style.file), the style sheet shared by all files;

– a set of index files for each series: series_NAME.html, series_NAME_compact.html, series_NAME_reverse.html, series_NAME_flat.html and their combinations;

– an index file tags_TAG.html for each tag;

– feed.xml, the RSS feed (see Series and tags).

Each card is rendered as a column with a header (containing the card's title) and a footer (containing the series navigation). Each fragment and each note is preceded by an HTML anchor, named after its identifier, so any fragment or note can be linked to from outside as FILE.html#IDENTIFIER. Each page also refers to the RSS feed at deck.url/feed.xml, so set deck.url for published decks. Cards with mathematics load MathJax 3 (with the amscd package) from the jsDelivr CDN.

The output is customised with the following attributes. Remember that html.style, html.head and html.title are lists: always set them with the plus sign.

html.style on the deck: CSS appended to style.css. This is the main means of changing the look of the output. The style sheet of this manual (fonts, colours, layout of the header and footer) is defined this way in self.conf:

/// +html.style p { text-align: justify; }
/// +html.style a { color: #2288bb; text-decoration:underline; }

html.style on a card: CSS placed in a style element in the card's file.

html.style on a fragment: inline CSS for the fragment's element:

This paragraph is red.
/ +html.style color: red;

html.head: lines added to the head element of the card's file, for example, to include a script. Inherited.

html.title: a prefix for the title of each HTML file. Inherited.

html.file and html.anchor on a card, html.anchor on a fragment: override the file name and the anchor names.

The style sheet starts with built-in rules, which html.style can override. The following elements and classes are used by the generated HTML:

– .column: the column containing a card; header and footer: its header and footer;

– code.inline: inline code produced by the cd style;

– span.annotation: text with a note attached, and the notes themselves;

– span.linktarget: the target span of a link;

– .margin-left and .margin-right: the left and right margins, holding link marks, fragment identifiers and notes; span.frag-id: a fragment identifier;

– .align-left, .align-right and .align-centre: the alignment styles;

– table.no-borders: the tables of the series and tag indices.
