Notes

A note is a short text attached to a part of a fragment. The HTML engine renders notes on the right margin and underlines the part of the text they are attached to. Each note gets a colour from a cycle of six, so neighbouring notes are usually distinguishable. A note is created with

/ +* "REGEX" TEXT

where REGEX selects the part of the fragment to which the note is attached (the same rules as for the spans in links apply, see Links) and TEXT is the text of the note, extending to the end of the line. Note text is subject to styles. Lines starting with : that immediately follow set attributes of the note, for example its identifier. Example:

This paragraph talks about one thing and then another thing. A lot of
marginalia are inserted here for demonstration purposes.
/ +* "one thing" Also described in the next paragraph
: id one
/ +* "another thing" Which is actually a _generalisation_ of the one thing.
/ += !phases-syntax "sentences" -> . "marginalia"
/ += https://www.example.com -> . "inserted"
/ +* "then" Add more colours.
/ +* "demonstration" Add even more colours.
/ +* "purposes" And more

The result looks like this: This paragraph talks about one thing and then another thing. A lot of marginalia are inserted here for demonstration purposes.

The note's regular expression cannot contain a double quote.

If you compare the example with the source of this card, you will see that the two link lines are not attached to the result paragraph itself. They are attached to the paragraph after it and refer to the result as "!notes-demo" instead of ".". This works around a bug in the current version: a fragment's link attributes are also applied to each of its notes, so on a fragment with notes, links like these come out duplicated and nested.

Notes can contain hyperlinks. A link is added to a note by a : line, in the same way as a link is added to a fragment by a / line. In a note's link attribute, . refers to the note itself:

/ +* "REGEX" TEXT
: += . "REGEX" -> TARGET

See Links for the details.

: += . "Links" -> !links-top

The : lines must immediately follow the note's / +* line (or each other). A link attribute can also be attached to any other fragment and refer to the note by its identifier, which is how links into notes of other cards are made:

/ += !notes-linkdemo-see "Links" -> !links-top

Links defined on the card or on the deck, including automatic links, apply to notes as well, and, as described above, so do the link attributes of the note's fragment.

A span in a note can be either end of a link. When it is the target, the matched text is underlined and the numbered mark linking back to the source is placed in the left margin of the note's fragment. However, notes have no HTML anchors, so hyperlinks leading to a note, as well as the back-links of links whose source is in a note, lead nowhere.
